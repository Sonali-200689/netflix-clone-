# Netflix Clone 🎬

A fully responsive, pixel-perfect clone of the Netflix landing page interface, built to practice semantic HTML5 structure and modern CSS layouts.

## 🔗 Live Demo
You can explore the fully functional live site here: 
👉 [Live Demo Link](https://sonali-200689.github.io/netflix-clone-/)

## 🛠️ Features Implemented
•⁠  ⁠*Semantic HTML5:* Clean structure separating the Hero gate, navigation, movie display grids, and footer.
•⁠  ⁠*Modern CSS Grid & Flexbox:* Utilized to create the iconic, responsive multi-column movie tile grid layout.
•⁠  ⁠*Responsive Layout:* Completely optimized with media queries to adapt flawlessly across mobile, tablet, and desktop screens.
•⁠  ⁠*Clean Code Architecture:* Organized asset management and modular stylesheet implementation.

## 🧰 Tech Stack
•⁠  ⁠*Markup:* HTML5
•⁠  ⁠*Styling:* CSS3 (Flexbox, Grid, Media Queries)
